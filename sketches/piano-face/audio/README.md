# Audio — Piano Face

Drop the spoken-word file here as **`speech.mp3`** (exact filename).

```
audio/
└── speech.mp3
```

`.mp3` is recommended for broad browser support and small file size.
`.m4a` and `.ogg` also work; if you use a different format, update the
`audio` field in `../metadata.json` accordingly.

While this file is missing, the unlocked sketch page shows a friendly
"audio not yet added" placeholder instead of an empty player.
